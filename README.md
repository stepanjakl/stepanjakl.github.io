## Browser Support

This website is designed to work on modern browsers targeting baseline support from **July 2015** and later:

| Browser | Minimum Version | Release Date |
|---------|----------------|--------------|
| Chrome | 44+ | July 2015 |
| Firefox | 39+ | July 2015 |
| Safari | 9+ | October 2015 |
| Edge | 12+ | July 2015 |
| Opera | 31+ | July 2015 |

### Progressive Enhancement

- **Core functionality** works without JavaScript using CSS (`:target`, `:checked`, `:focus-within`)
- **Enhanced experience** with JavaScript for improved accessibility and UX
- **Reduced motion** support for users with vestibular disorders
- **PWA capabilities** with offline support via Service Worker
- **Responsive design** optimized for all screen sizes from mobile to desktop

### Key Technologies

- Pure HTML5, CSS3, and vanilla JavaScript (no frameworks)
- Custom Elements (Web Components) for timeline functionality
- IntersectionObserver API for scroll-based animations
- Service Worker for offline functionality and caching
- Progressive Web App (PWA) with manifest.json
